# OBD2MQTTS

A clean, modular ESP32/Arduino project for reading OBD2 battery telemetry and publishing it securely over MQTT with TLS (MQTTS).

Designed for:
- Hyundai Ioniq
- Adaptable to other vehicles or setups with similar OBD2 access

The project is built to:
- read battery telemetry from the vehicle over OBD2
- convert the data into a structured format
- publish it to an MQTT broker using a secure TLS connection

The code is organized to stay modular, readable, and easy to extend.
